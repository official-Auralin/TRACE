Read the board

Follow the signal from START, across moments, to the one lamp labelled TARGET. Earlier ON/OFF boxes show what happened along the way; they are not extra goals. Routes are different machine states, not different positions of the same switch.

Copies with exactly the same full label are one switch and change together. The same letter at a different moment is a different switch. A mark selects its recorded position; clicking does not flip it. CHANGE may change some or all marked switches. Any set passing the three tests is accepted, even if another answer uses fewer marks.

Use drag, scroll, zoom, or the Moment/Route controls to explore. Arrow keys pan when the board is focused. Every input remains available in the switch list.
