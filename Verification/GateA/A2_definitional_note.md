# A2 (definitional half) — Which CORP contingency setting generated TempoBench's TCE keys?

**Question (mainTB's own roadmap V2 TODO):** "verify against Coenen et al. (ATVA 2022)
whether their contingencies permit non-actual values, and record the answer here."

## Answer: CORP's contingencies were **DISABLED** for the shipped keys (author-confirmed)

The TempoBench authors confirmed directly (2026-06-14) that the TCE ground-truth keys were
generated by **CORP with contingencies disabled**. This *supersedes* the earlier
primary-source inference in this note (which read CORP's contingency mechanism from the
papers but could not know the toggle state of the shipped keys). The toggle state is now
known, so the variant question is settled.

**What "contingencies disabled" means for the key object.** CORP implements actual
causality in Halpern's *modified* variant; its contingency mechanism lets the counterfactual
"jump" selected **outputs** back to their actual-trace values (Coenen et al., ATVA 2022,
Def. 4; Finkbeiner et al., CAV 2024, Remark 2 — both author-hosted/arXiv versions). With
that mechanism **off** there is no contingency at all, so the key is the **contingency-free
counterfactual cause**: the subset-minimal set of input cells whose flip (every other cell
at its recorded value, the device run forward, no resets) destroys the effect. On the
TCE point-effect task over (F2)–(F3) transducers this is exactly the engine's
`minimal_flip_sets` — the joint-flip object the **CREDIT·JOINT** surface
(`TRACE_credit_joint.html`) grades.

## Relationship to mainTB's Def. actual

| | mainTB Def. actual | CORP / TempoBench keys |
|---|---|---|
| HP variant | original/updated (HP 2005) | modified (Halpern 2015), **contingencies disabled** |
| Contingency variables | **input** cells (exogenous) | outputs/states — but **off** for the keys |
| Contingency values | possibly **non-actual** | none used (disabled) |
| Effective object | minimal *actual causes* (atomize to singletons, Prop. atomize) | minimal *joint-flip* sets (contingency-free) |
| Witness on Puzzle 3 | `{(0,a)}`, `{(0,b)}` (singletons) | `{(0,a),(0,b)}` (joint pair) |

The two readings give **different witnesses on overdetermined instances** (singletons vs.
the joint pair). **But at the per-cell granularity TempoBench grades they coincide:** the
per-cell union is variant-invariant (mainTB **Prop. union**, machine-checked in
`../GateB/verify_atomization.py`: `union(minimal_actual_causes) == union(minimal_flip_sets)`
exhaustively for windows ≤4 and on random 5–6). So `Γ^ac` equals the per-cell key on every
(F2)–(F3) instance, overdetermined or not.

## Consequences (replacing the earlier "unsupported / predicted divergence" reading)

- **Conjecture corp is no longer variant-conditional.** The setting is confirmed
  (disabled) and the per-cell union is variant-invariant, so the only residual is CORP's
  ω-regular cause representation vs. TempoBench's per-cell flattening, checkable on the full
  dataset (`a2_corp_compare.py`). The previous "definitionally unsupported / symmetric
  overdetermination is the predicted divergence class" reading was predicated on not knowing
  the toggle state and on conflating witness-granularity divergence with per-cell divergence;
  it is withdrawn.
- **Variant policy (A3) confirmed.** TempoBench-alignment corpora grade the modified,
  contingency-disabled object (CORP's own); the original/updated variant is mainTB's
  independent per-cell-credit stance. The two differ only at the witness/all-causes
  granularity; the per-cell key is shared.
