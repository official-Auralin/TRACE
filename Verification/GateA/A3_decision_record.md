# A3 — HP-Variant Decision Record (governs hp_variant_policy in the instance schema)

**Evidence base:** a3_variants.json (machine-verified on the five gold puzzles) and
A2_definitional_note.md (now an **author-confirmed** record: TempoBench's keys were
generated by CORP with **contingencies disabled**, 2026-06-14).

## Findings
1. The original/updated and modified variants **agree on every non-overdetermined
   instance** (P1, P2, P4) and **diverge exactly on overdetermined ones** (P3, P5):
   original/updated returns the singletons; modified returns the joint pair.
   (Verified mechanically; matches mainTB's own analysis.)
2. **CORP implements the modified discipline** (output-resets to actual values,
   toggleable), and **TempoBench's shipped keys were generated with that toggle OFF**
   (contingencies disabled, author-confirmed) — see A2_definitional_note.md. So the keys
   are the contingency-free joint-flip object; mainTB's Def. actual implements
   original/updated over input cells.
3. **The per-cell union is variant-invariant** (mainTB Prop. `union`,
   machine-checked in `../GateB/verify_atomization.py`): the original/updated and
   modified readings differ only in how cells *group* into witnesses (singletons vs.
   joint sets), never in the per-cell set TempoBench grades. So the keys equal `Γ^ac`
   per-cell on every instance, overdetermined or not.
