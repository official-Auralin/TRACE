# Proof coverage

The primary contract is `InclusionMinimal (Combined value actual E) C`, where `Combined = Guarantee ∧ Prevention`, `Guarantee C = ¬Bad C`, `Prevention C = Bad(complement C)`, and `Bad F` means that some complete input word agrees with every fixed recorded cell in `F` and makes the target output false. The actual target must be positive. Every inclusion-minimal valid set is acceptable; minimum cardinality is a different task.

| Obligation | Checked theorem(s) | Scope and assumptions |
|---|---|---|
| Total deterministic Mealy replay and prefix locality | Vendored `TraceReview.mealy_state_unique`, `mealy_output_unique`, `mealy_output_prefix` | Given a total `TotalMealy` machine; output uses the pre-transition state. |
| Bad is antitone in fixed cells | `bad_antitone` | Arbitrary world/effect; no monotonicity of the target Boolean function is assumed. |
| G, P, and their conjunction are upward closed | `guarantee_upward`, `prevention_upward`, `combined_upward` | Cells denote equality to their actual values, including zero. |
| Inclusion minimality equals validity plus failure of every single deletion | `minimal_iff_single_deletions` | Any upward-closed set predicate. |
| One deletion pass terminates and returns an inclusion-minimal answer | `prune_valid`, `prune_protects_visited`, `prune_minimal` | Supplied decidable predicate must be correct and upward; starting candidate valid; inventory complete. Termination is structural recursion on inventory. `prune_checks_eq_length` states the corresponding loop-count recurrence; it is not a runtime complexity theorem about Python. |
| Finite existential recurrence equals target-defeating replay | `badEval_iff`, `badFrom_iff_replay`, `replayOutput_eq_mealy` | Complete finite input alphabet; forced machine transitions. |
| Checking every table equation is sound and complete | `checkTable_iff`, `localTable_exact`, `canonicalTable_checked`, `localTable_unique` | Complete state inventory; every row/state is checked, including unreachable ones. Every instance has the canonical table, and accepted tables are unique over the target window. |
| Positive root proves existence; false root proves absence | `checked_table_replay_iff`, `checked_false_iff_no_replay` | Full recurrence checking, not path sampling or bounded lasso testing. |
| Boolean input alphabet is complete | `allValuations_complete` | Every `Fin m → Bool` valuation occurs; adapter additionally checks integer encoding is a bijection onto table columns. |
| Cell fixing and temporal permissions agree | `allowedFix_iff`, `permitted_iff_fixes` | Cell type is `Fin(target+1) × Fin m`. |
| Checked table roots mean exactly Bad(F) | `checked_root_iff_bad` | Composes recurrence, alphabet, window fixing, and actual-value semantics. |
| Finite window determines the effect | `window_determines_effect` | Obtained from the vendored Mealy prefix theorem. |
| Local minimal-answer certificate is sound and complete | `minimalCheck_combined_iff` | Only the candidate and selected single-deletion roots and their complements need be certified. |
| Reference semantic decision is sound and complete | `finiteBad_iff`, `finiteMinimalCheck_iff` | `finiteBad` defines the canonical recursive recurrence. It is retained as a proved reference, not rerun by the efficient certificate adapter. |
| No-explanation verdict | `combined_exists_iff_failure`, `no_explanation_check_iff`, `finiteNoExplanation_iff` | Actual effect positive and completely determined by the finite window. No valid set exists iff the completely free query has no target-defeating input. |
| Finite explainer/challenger policy corresponds to G∧P | `winning_policy_iff_combined`, `no_winning_policy_iff` | Candidate fixed before play. Challenger chooses the branch and all legal guarantee inputs; explainer chooses a prevention word. Deterministic evolution makes a whole-word policy sufficient. |
| Absorbing parity padding preserves the finite result | `padded_min_even_iff`, `parity_game_iff_combined` | Finite prefix has priority 2, successful sink 0, unsuccessful sink 1; min-even convention. This is a bounded verification game, not synthesis-strategy necessity. |
| Runtime cell inventory is complete | `Runtime.cellOrder_complete` | Every finite time/channel pair is in the decision inventory. |
| Serialized cell keys cannot alias distinct selections | `Runtime.cellId_injective`, `Runtime.mem_maskCells`, `Runtime.maskCells_injective` | Keys list the selected cells in canonical time/channel order. |
| Checked sparse lookup is semantically bound | `Runtime.checked_query_binding`, `Runtime.rootsSound_append_checked`, `Runtime.rootsLookup_eq` | Each inserted table is locally checked; only present keys can justify decisions. The lookup definition is the runtime definition. |
| Required queries cover all accepted-answer obligations | `Runtime.covered_key_present`, `Runtime.checked_lookup_minimal_iff`, `Runtime.checked_lookup_no_explanation_iff` | Uses the same `requiredKeys`, `rootsCover`, and lookup functions as the runtime. |
| General switch construction reads the original inputs | `compileBits_correct`, `flatInput_cell`, `cellId_injective`, `compileRound_correct` | Arbitrary finite channel count; every switch uses its original time/channel identifier; duplicate appearances are linked. |
| Equality reduction preserves each round | `simplifyTree_correct`, `compileRoundReduced_correct` | Equal subtrees can be merged without changing any input assignment's result. No cell is removed from the intervention domain. |
| General construction preserves every output round | `compile_outputs`, `compile_target`, `compile_reduced_outputs`, `compile_reduced_target` | Arbitrary total deterministic machine and finite target. Loops and outputs that turn off after turning on are included. No requirement that the target is positive is needed for these equivalences. |
| General construction preserves every valid minimal explanation | `compile_combined`, `compile_minimal_explanations`, `compile_reduced_minimal_explanations` | Same world, cell inventory, actual assignment, target, and intervention domain. The executable reduced constructor is included. |
| Mapping and reduction preserve the terminal outcome | `mapLeaves_correct`, `terminalDisplay_correct`, `compileTerminal_correct` | Project each semantic `(next, output)` leaf to `output`, then reduce equal branches. The actual CLI calls this proved definition. Post-target state is intentionally absent from this display. |
| Earlier routing and complete semantic state replay are preserved | `displayOutput_before_target`, `compile_reduced_states` | Before the target, display evaluation uses the unchanged semantic tree's next-state component. The complete semantic forest retains every state, including the state after the target. This is not a claim that an output-only leaf encodes that state. |
| The terminal display preserves the target and all explanations | `compile_display_outputs`, `compile_display_target`, `compile_display_combined`, `compile_display_minimal_explanations` | Full semantic routing before the target, projected output-only tree at the target; same cells, actual assignment and intervention domain. Equal current outputs in earlier rounds are not enough to merge their transitions. |

`Trace2.Runtime` decodes the real JSON certificate schema and calls `checkTable`, `rootsLookup`, `rootsCover`, and `minimalCheck`. `CompilerRuntime` calls the proved `compileRoundReduced` and `compileTerminal` definitions and serializes the semantic forest plus the terminal display forest. Their JSON/IO orchestration is not itself a theorem over bytes. Both runners compile in the clean build; source and native executable hashes are recorded. `benchmark.verify` supplies concrete records and checks canonical instance binding; its reports are the evidence that those records passed.

Not mechanized here: the optional hypergraph characterization by minimal failure supports and hitting sets; JSON parsing and serialization; assembly of the complete array of serialized per-state/per-round trees; equivalence of the Python optimizer or browser interpreter source to Lean source; arbitrary temporal monitor compilation; full strategy reversal/N2 in the original synthesis game. These must not be included in the proof count or described as consequences of the finite theorem without further work. The first is supported by the manuscript's mathematical argument and independent finite checks; application boundaries receive separate operational tests.
